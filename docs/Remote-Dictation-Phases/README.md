# Remote Dictation phases

Immediate cursor insertion of a finalized dictation transcript from one Personal Voice device to another selected device on the same account.

Not Handoffs. Not Assistant remote computer actions.

## Finished experience

Tap the Remote Dictation button to choose another device. Hold it and speak. Release, and the text appears at that device's cursor.
